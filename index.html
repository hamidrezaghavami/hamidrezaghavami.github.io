nodejs/node #64238

util: allow single-line format when break length is infinite

Merged • Sep 2026 View PR ↗
Added an early return in util.inspect's isBelowBreakLength when breakLength is Infinity, skipping line-width calculations that can't change the result. Output is unchanged, so this is a small performance cleanup, not a bug fix. Worked through maintainer feedback on the test and lint rules.

nodejs/node #64397

fs: return Buffer from mkdtemp when prefix is a Buffer

Merged • Sep 2026 View PR ↗
Fixed a bug where fs.mkdtemp, mkdtempSync, fs.promises.mkdtemp and the disposable variants returned a string for a Buffer prefix, which could mangle non-UTF8 paths (fixes #58795). Now forces encoding: 'buffer' for Buffer prefixes across all APIs, with new regression tests and docs history. A semver-major change that needed TSC approval and several rounds of review; shipped in Node.js 27.

nodejs/node #64341

fs: accept all valid utf8 values in fast paths

Open • In Review View PR ↗
Fixes a 3-year-old issue (#49888) where the UTF-8 fast paths only matched lowercase utf8 and utf-8, so UTF8 and UTF-8 silently took the slower path. Adds a small isUtf8Encoding helper so readFileSync, writeFileSync and encodeRealpathResult use the fast C++ path for every valid UTF-8 spelling, and extends it to the Buffer I/O fast paths. Under review.
